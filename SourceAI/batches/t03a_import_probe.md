# T03a — пробные текстуры для Unity

Вариант **01**, изготовлен для проекта «Пепельный маяк» 28.11.2026. Задача, профиль и проверка описаны в [спецификации T03a](../../docs/specs/T03a-art-import.md).

**Происхождение.** Оригинальные технические образцы созданы непосредственно для проекта. Unity 6000.6.10f1 записала PNG из пикселей, заданных детерминированной процедурой C# (`Texture2D.SetPixels32` и `EncodeToPNG`). Палитра и геометрия заданы в процедуре. Внешних изображений, шрифтов и референсов нет. Генеративный сервис, промпт и seed не применялись. Ручная ретушь не требовалась. Готовые PNG содержат исходные пиксели. Основание использования — собственные материалы проекта без сторонних лицензий.

| Файл | Роль и параметры |
|---|---|
| [env_import_probe_floor_01.png](../../Assets/AshBeacon/Tests/Editor/ArtImport/env_import_probe_floor_01.png) | Пол, 32 × 32 px, непрозрачный. Внешние два пикселя по периметру одного цвета для повторения по обеим осям. Pivot по центру (16, 16 px) |
| [prop_import_probe_glow_sheet_01.png](../../Assets/AshBeacon/Tests/Editor/ArtImport/prop_import_probe_glow_sheet_01.png) | Прозрачный лист 64 × 32 px. Ячейки 32 × 32 px слева направо: приглушённое и яркое свечение над общей опорой. Pivot (16, 6 px от нижнего левого угла каждого кадра) |

У образцов технические роли без игровых ID и без эталона T03b. После подготовки PNG в Editor настроены режим, масштаб и Android override. Лист нарезан на два именованных кадра с сохранёнными локальными ID. Сопоставление файла, `.meta` и потребителей выполняется по соседним файлам в каталоге `Assets/AshBeacon/Tests/Editor/ArtImport/`.

Для обоих файлов проверено побайтовое восстановление из LFS-указателя в отдельном локальном хранилище. SHA256 тайла — `477fbe43e3376e22d2a03ae0b1bdbda601e234ecffd6ed732727879a66c08843`. SHA256 листа — `cfee7858a8598d162454249c8baad8b80d8dae588531131668a4a784b0c48dba`.
