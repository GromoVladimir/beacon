# Пепельный маяк

«Пепельный маяк» — одиночное 2D-приключение для Android с видом сверху, экранным миром, направленным боем и инструментами, открывающими новые пути. Горизонтальная ориентация, офлайн. Название утверждено владельцем 22.11.2026.

**Статус:** SDD-план MVP согласован, T00 завершена. Владелец обновил Unity до 6000.6.10f1 и выбрал Android; основной тестовый телефон — Samsung S25 Ultra. В репозитории Unity-шаблон и документы; игровая логика, тесты, CI и игровые build profiles ещё не реализованы. Полная кампания не является первым этапом разработки.

## Стек и запуск шаблона

Unity **6000.6.10f1**, C#, URP **17.6.0** / 2D Renderer, Input System **1.20.1**, uGUI **2.6.0**, Unity Test Framework **1.8.0**. Точные зависимости — в `Packages/manifest.json` и `packages-lock.json`. Не обновлять Editor/пакеты автоматически.

1. При работе с клоном установить Git LFS и загрузить LFS-объекты, если они есть; `.gitattributes` уже содержит правила для бинарных ассетов.
2. Через Unity Hub установить точный Editor. Для телефона нужны Android Build Support, SDK/NDK/OpenJDK.
3. Добавить корень репозитория как существующий проект и дождаться восстановления пакетов/импорта.
4. Открыть `Assets/Scenes/SampleScene.unity`. Сейчас Play запускает только шаблон; игровых Bootstrap/MainMenu/Gameplay ещё нет.
5. Перед реализацией прочитать документы и решения T00. Проверки и будущие команды сборки — в [testing.md](docs/testing.md).

## Проверка файлов проекта

Из корня репозитория в PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/Check-Baseline.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools/Test-Baseline.ps1
```

Политика выполнения меняется только для дочернего процесса. Эти проверки не заменяют
Unity EditMode/PlayMode и Android-сборку. Игровых тестовых сборок и build entrypoints
пока нет; при открытом Editor второй batch-процесс над этим проектом не запускать.

## Объём игры

Первый срез: 6 внешних экранов, отдельный храм из 6 комнат, E01/E03/E04/E06, босс B1, меч, щит, бумеранг, один секрет, сохранение. После его приёмки — полный D1, остальные инструменты, затем кампания: 36 внешних экранов + 64 комнаты подземелий, 20 врагов и 5 боссов.

Сервер, облачные сохранения, реклама, мультиплеер и крафт не входят в v1. `.env.example` не нужен: игра не использует внешние API; секреты подписи/CI позднее передаются вне репозитория. Никакие лицензии на сторонние ассеты наличием этого репозитория не предоставляются; используемые ресурсы нужно учитывать отдельно.
