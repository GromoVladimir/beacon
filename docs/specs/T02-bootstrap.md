# T02 — вход в приложение и проверочная комната

Статус: **DONE**, 22.11.2026. Зависимость T01 выполнена. [Отчёт](../reports/T02-bootstrap.md).

## Цель и границы

FR-01 (только каркас входа), NFR-06; GDD §3.1, §16–17;
architecture.md §3–4. Вход Bootstrap → MainMenu → Gameplay, возврат в меню,
один постоянный корень композиции и отдельная сессия на каждый запуск.
Проверочная комната 20 × 12 клеток, фиксированная ортографическая камера.
Domain/Application не используют UnityEngine; зависимости передаются явно.

Не входят: движение/пауза T03, бой, сохранения/продолжение T08–T10,
кампания, настройка сборки/CI T06. Запуск прототипа не читает и не удаляет
сохранения. Полное FR-01 этой задачей не закрывается.

## Контракты и ошибки

Application получает порт загрузки MainMenu/Gameplay. Пока выполняется загрузка,
повторная команда отклоняется. Сессия меняется только после успешной загрузки.
Ошибка загрузки передаётся вызывающему коду, предыдущее состояние и сессия
сохраняются, блокировка снимается для повторной попытки. Адаптер загрузки обязан
завершать операцию только после готовности сцены; восстановление геометрии при
ошибке Unity проверяется интеграционно, не выводится из unit-тестов.

## Критерии и проверки

1. Bootstrap воспроизводимо открывает MainMenu; старт открывает Gameplay.
2. Повторный Bootstrap не дублирует корень/сервисы; возврат удаляет сессию,
   новый старт создаёт новую. Проверка PlayMode, включая повторный вход.
3. В Gameplay одна пустая проверочная комната и камера; нет Missing Script/reference.
4. asmdef ядра имеют noEngineReferences, Application зависит только от Domain.
5. EditMode: штатный цикл, повторная команда во время загрузки, ошибка и повторная
   попытка, отсутствие потери сессии при ошибке возврата.
6. Импорт в точном Editor; EditMode/PlayMode > 0, Console без новых ошибок.

## Результат и ограничения

Все критерии подтверждены: EditMode 6/6, PlayMode 3/3, live-проверка пяти сцен
без отсутствующих скриптов/ссылок; основной Editor 6000.6.10f1, Android.
Владелец подтвердил проверку по ручному чек-листу запуска и интерфейса.
Сцены созданы через Editor, ядро не зависит от UnityEngine.

CLI не подключался, поэтому использован Unity MCP. После прерывания окружения
связь восстановлена, тесты завершены. Переопределение playModeStartScene убрано:
для ручного запуска открыть Bootstrap; Test Runner запускает собственную сцену.
Обновления Editor/пакетов и миграции данных не выполнялись.
Android-сборка нового каркаса и lifecycle на телефоне остаются в T06/T03.
