# T01 — окружение и baseline

Статус: DONE — статическая и live-проверки пройдены через Unity MCP.
Зависимость T00 выполнена. Дата: 22.11.2026. [Отчёт](../reports/T01-baseline.md).

## Цель и границы

Подтвердить исходное окружение после обновления владельцем, не меняя Editor
и пакеты. Допустимы адресные исправления подтверждённых отсутствующих ссылок
шаблона через Editor, без изменения игровых правил. Требования: NFR-05, NFR-07; GDD §17–18.
Входы: Assets с meta, Packages manifest/lock, ProjectSettings, установленный Editor.
Выходы: воспроизводимая статическая проверка и отчёт с отдельным статусом live import.
Игровые модули не затрагиваются. Bootstrap, asmdef, движение, бой и APK вне T01.

## Критерии приёмки

1. Точный Editor 6000.6.10f1 открыт на этом проекте, импорт завершён, нет ошибок
   компиляции/импорта и Missing Script. Версия в файле не заменяет эту проверку.
2. Записаны установленные Android Build Support, SDK/NDK/OpenJDK и версии пакетов.
3. Force Text и Visible Meta Files подтверждены.
4. Нет пропущенных/дублированных meta GUID и отсутствующих GUID-ссылок проекта;
   внешние ссылки разрешаются в импортированных пакетах. Проверка GUID не доказывает
   корректность fileID/subasset или поведения сцены — это проверяется в Editor.
5. Git LFS доступен и настроен, исходные бинарники не заменены указателями.
   Если HEAD отсутствует, fsck помечается непройденным, а не успешным.
6. Результаты и ограничения записаны; DONE только при выполнении всех критериев.

## Проверки и ошибки

`tools/Check-Baseline.ps1` проверяет файлы без записи и без запуска Editor.
Отсутствующие входы, неверная версия, рассинхронизация manifest/lock, неправильные
настройки сериализации, пропущенные meta, дубли GUID, битые GUID-ссылки и LFS pointers
дают исключение и ненулевой код завершения процесса.
`tools/Test-Baseline.ps1` проверяет валидную fixture и повреждённые варианты.
Для live-проверки: статус Editor → Console cursor → завершение импорта → Console errors
и Missing Script в SampleScene. Не очищать Console. Не запускать второй Editor
над открытым проектом и не пересохранять сцены массово.

## Риски и восстановление

Точка восстановления до изменений: чистый коммит `37c3415`. Изменены только два
ассета шаблона через Editor; GUID и meta сохранены. Устаревшие APV-поля подтверждены
исходниками установленного URP (`Runtime/Deprecated.cs`); удалены отсутствующая
зависимость шаблона и неиспользуемые ссылки. Сохранение Editor нормализовало формат
этих двух ассетов. Новых пакетов и игровых миграций нет. Проверка текущего каталога
с Library не доказывает чистую сборку; она остаётся задачей T06.

## Результат 22.11.2026

Все шесть критериев выполнены: версия/Android tools подтверждены живым Editor,
импорт и компиляция завершены, обе сцены проверены без Missing Script/reference,
static baseline PASS, 15 положительных/отрицательных сценариев PASS, LFS fsck OK.
Воспроизводимая live-проверка — `tools/Verify-Baseline.cs` через `script_eval(file)`;
она не входит в Assets и Android-сборку. Результаты и ограничения — в отчёте.
