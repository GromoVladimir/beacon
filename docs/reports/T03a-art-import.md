**DONE · 28.11.2026.** Критерии T03a подтверждены в Unity Editor.

## Результат

Два технических PNG импортированы в Unity 6000.6.10f1. [Проверочный prefab](../../Assets/AshBeacon/Tests/Editor/ArtImport/ArtImportProbe.prefab) содержит четыре экземпляра тайла пола на Tilemap и SpriteRenderer со свечением. Клиповый ключ переключает спрайт в 0,50 с. Оба кадра имеют одинаковую точку опоры. В Animator состояние Glow по умолчанию проигрывает зацикленный клип.

| Параметр | Тайл | Лист |
|---|---|---|
| PNG | 32 × 32 px | 64 × 32 px, два кадра 32 × 32 px |
| Режим | Single | Multiple |
| Pivot | 16, 16 px | 16, 6 px в каждом кадре |
| Общее | 32 PPU, Point, Clamp, без mipmaps и сжатия, Max Size 256 | 32 PPU, Point, Clamp, без mipmaps и сжатия, Max Size 256 |
| Android override | RGBA32, Max Size 256 | RGBA32, Max Size 256 |

## Воспроизведение

1. В Test Runner открыть EditMode и запустить `AshBeacon.Tests.ArtImportTests`. Тесты измеряют площадь четырёх тайлов, сравнивают пиксели на противоположных краях и проверяют временную копию с 16 PPU.
2. Для ручного просмотра открыть prefab в Prefab Mode. В Scene View видны четыре клетки пола. Выбрать дочерний объект Glow и открыть окно Animation. В Preview проиграть ImportProbeGlow или перейти на 0,25 и 0,75 с. Свечение меняется, опора остаётся на месте.
3. Через Project → Reimport повторно импортировать оба PNG. Снова открыть prefab и клип. Автотест повторяет импорт, сравнивает GUID и локальные ID всех трёх спрайтов и проверяет сохранённые ссылки и смену кадра до и после импорта.
