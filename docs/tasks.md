## Контракт задачи

Перед реализацией создать `docs/specs/Txx-<name>.md`: цель, связанные FR/NFR и GDD §, входы/выходы, затрагиваемые модули, штатные/ошибочные сценарии, критерии приёмки, проверки, миграции/риски, вне объёма. Новые правила сначала обсуждаются/фиксируются, затем реализуются. Малую задачу завершать одним обозримым изменением; если она разрастается, разбить на дочерние ID до кодирования.

Статусы: TODO → SPEC_READY → IN_PROGRESS → REVIEW → DONE; BLOCKED обязательно содержит вопрос и зависимость. DONE: критерии подтверждены, тесты прошли, результат демонстрируется, документация актуальна, нет новых необъяснённых предупреждений. Для зависимости достаточно не наличия кода, а принятого результата.

После приёмки T03 завершены пробный импорт T03a и эталоны T03b. T04 завершила базовый прототип боя. Доступна T05 по врагам. Следующий пакет графики T06a зависит от T06. ## Покрытие и ограничения

Каждый FR-01…FR-28 и NFR-01…NFR-10 указан хотя бы в одной задаче; при добавлении требования добавляется задача и тест. Базовую автоматизацию тестов/сборки добавить в T06, затем запускать при каждом изменении; T36 завершает release-процесс, не откладывает тестирование до конца.

Не включены: установка платных ассетов, подключение облачных сервисов, публикация, пуш/merge и дальнейшая смена версии Unity. Они не следуют автоматически из завершения очередной задачи. Согласование MVP завершено. T03 принята владельцем, T03a, T03b и T04 завершены. По зависимостям доступна T05. Полную кампанию начинать только после приёмки среза и решения о расширении по roadmap.
